LESSON 01 OF 09 • DIAGNOSTIC MINDSET

The Diagnostic Loop: How Tier-1 Thinks

Amateur techs guess and burn 45 minutes reinstalling apps, clearing random caches, or rebooting blind. Good Service Desk engineers cut the problem space in half with every question and fix the same ticket in 3 minutes.

● HOW AMATEURS WASTE TIME

User says "My email isn't working." The amateur immediately rebuilds the Outlook profile, reinstalls Office, and escalates to server admins—only to realize 40 minutes later the user's Wi-Fi switch was toggled off.

● HOW TIER-1 ISOLATES FAST

Start at the physical and obvious layer, test scope (one app vs. whole PC; one user vs. whole floor), change one variable at a time, verify with the user, and log clean notes so nobody repeats your work.

WORKFLOW The 6-Step Diagnostic Loop

STEP 01

Identify the Problem

Ask Who, What, When before touching anything. "What exact error pops up? When did it last work? Did anything change—Windows update, new password, moved desk?"

STEP 02

Check the Obvious

Verify power lights, loose HDMI/Ethernet cables, laptop Wi-Fi switch, Caps Lock on login screens, and whether they clicked Restart vs. Shut down.

STEP 03

Isolate the Scope

Is it broken in 1 app or the whole PC? Happening to 1 user, 1 department, or the entire office? Scope tells you whether to fix a laptop or escalate a server outage.

STEP 04

Test a Theory

Form one clear cause and change one variable at a time. If you clear cache, reset DNS, and reinstall an app together, you won't know what actually fixed it.

STEP 05

Fix & Verify

Apply the fix, then watch the user test their real workflow (send an email, open the ERP, print a page). Never close a ticket just because your screen looks fine.

STEP 06

Document

Write concise ticket notes another tech can read in 10 seconds:
Symptom → Cause → Fix

FIELD TRAP • FAST STARTUP

Why "I Shut Down My PC Every Night" Is Often False

In Windows 10 and 11, clicking Shut down does not perform a full cold shutdown. Windows logs the user off, then hibernates the Windows kernel and loaded drivers to C:\hiberfil.sys so the laptop boots faster the next morning.

Start → Shut down Keeps kernel bugs, memory leaks, and hung drivers alive. System Up time stays at 12+ days.
Start → Restart Forces Windows to unload the kernel completely, reload drivers clean, and reset System Up time to 00:00:00.

LESSON 02 OF 09 • WINDOWS WORKBENCH

Core Windows Tools (Your Daily Workbench)

Learn the exact shortcuts to open these five utilities in two seconds, what each screen exposes, and the specific red flags a Service Desk tech checks first.

1. Task Manager

Ctrl + Shift + Esc

Shows live running processes, hardware load, system uptime, and startup bloat.

  • [Processes] Spot frozen apps marked Not responding or eating abnormal RAM, select them, and click End task to unfreeze Outlook/Excel without rebooting.
  • [Performance] Check if CPU, Memory, or Disk is pinned at 100%, and read Up time at the bottom of the CPU screen to catch Fast Startup issues.
  • [Startup apps] Disable unnecessary consumer apps (Spotify, auto-updaters) that slow down morning logins.

2. Device Manager

Win + X → M

Lists every physical and virtual hardware controller Windows sees and the driver loaded for it.

  • [Yellow Triangle !] Driver error or missing driver (e.g., Code 43 or Code 28 on audio, dock, or GPU).
  • [Down Arrow ↓] Hardware is manually Disabled—common when users disable their Wi-Fi adapter or webcam. Right-click → Enable device.
  • [Driver Tab] If hardware broke right after a Windows Update, click Roll Back Driver. If glitched, click Uninstall device (leave "Delete driver" unchecked), then Action → Scan for hardware changes.

3. Windows Services

Win + R

Controls background Windows processes without a desktop window. Startup Types: Automatic, Automatic (Delayed), Manual, and Disabled.

  • [Print Spooler] Service name Spooler. Right-click → Restart clears stuck print queues in 5 seconds without rebooting the user's PC.
  • [Windows Audio] Service name Audiosrv. Restarting it fixes USB headset audio drops mid-day.

4. Event Viewer

Win + X → V

Windows' black-box flight recorder. Open Windows Logs → System and Application, then click Filter Current Log → Critical & Error.

Event ID 41 • Kernel-Power PC rebooted without a clean shutdown (power cut, dead battery, or held power button).
Event ID 1001 • BugCheck Windows hit a Blue Screen of Death (BSOD) and saved a crash dump—include this ID when escalating to Tier-2.

5. Control Panel vs. Settings

Win + I vs. control
MODERN SETTINGS (Win + I)
  • Windows Update & Optional Updates
  • Display scaling & multi-monitor layout
  • Bluetooth devices & Default apps
  • Work or school account (Entra ID)
CLASSIC CONTROL PANEL (control)
  • ncpa.cpl — Network Adapters & static IPv4
  • appwiz.cpl — Repair/uninstall Office & MSI apps
  • Credential Manager — Wipe bad cached passwords
  • mmsys.cpl — Classic Mic/Speaker defaults
LESSON 03 OF 09 • STORAGE & ACCESS CONTROL

File & Drive Basics: NTFS & Network Shares

Shared department folders break every day because of two things: wrong NTFS permissions or stale network drive mappings. Here is how Windows actually evaluates folder access.

NTFS Permission Levels (From Strictest to Highest)

Permission What the User Can Do Typical Office Use
Read View folder names, open files, and copy files out. Cannot save edits or delete. Company policy PDFs, HR handbooks.
Read & Execute Everything in Read, plus permission to launch .exe programs or scripts. Shared software installers folder.
Write Create new files/folders and overwrite content, but cannot delete existing files. Drop-box folders where staff submit reports.
Modify Read & Execute + Write + Delete files and subfolders. Standard permission for department shared drives.
Full Control Everything in Modify + change permissions & take file ownership. IT Admins only. Never grant to regular staff.
GOLDEN RULE #1

Explicit Deny Always Overrides Allow

If a user is in Sales_Staff (Allow: Modify) AND also in Contractors (Deny: Write), Windows blocks them from writing. Always check every group the user belongs to.

GOLDEN RULE #2

Network Access = Most Restrictive Wins

Over the network, Windows checks both Share Permissions and NTFS Permissions and enforces whichever is stricter. Example: Share = Full Control + NTFS = Read → User gets Read.

Mapped Network Drives (\\ServerName\ShareName)

A UNC Path points directly to a shared folder on another computer or file server using \\ServerName\ShareName (e.g., \\FS01\Finance). Mapping assigns that path a persistent drive letter like Z:.

# Map Z: permanently via Command Prompt:
net use Z: \\FS01\Finance /persistent:yes
# Clear broken cached drive sessions:
net use * /delete
ERROR A: "The network path was not found" Meaning: Windows couldn't reach the server at all. Check Wi-Fi/VPN connection, run ping FS01, check DNS, or verify the UNC path spelling.
ERROR B: "Access is denied" Meaning: Network connection works—security blocked the user. Check AD group membership, NTFS/Share permissions, or wipe old cached passwords in Credential Manager.
LESSON 04 OF 09 • FIELD OPS 01 • DEPLOYMENT & FIRMWARE

Windows Install & BIOS Boot

Fresh laptops arrive from vendors with bloatware or broken images, and crashed machines need clean installs. Know how to build bootable USB media, trigger one-time boot menus across brands, resolve missing NVMe drives, and build a local admin account offline.

1. Bootable USB Creation: Media Creation Tool vs. Rufus

OFFICIAL • AUTOMATED

Windows Media Creation Tool

Microsoft's official utility downloads the current Windows 10/11 image and formats an 8GB+ USB drive automatically. Simple, though slower when preparing multiple USB sticks.

DESK STANDARD • FAST

Rufus + Official Microsoft ISO

Preferred at IT desks because you flash a local ISO in 3 minutes and explicitly select the Partition Scheme and Target System to match the PC's firmware.

GPT + UEFI (non-CSM) → Modern PCs Required for Windows 11, Secure Boot, TPM 2.0, and drives over 2 TB. Use this on virtually all modern business laptops/desktops.
MBR + Legacy BIOS → 10+ Yr Old Hardware Only for legacy machines that lack UEFI firmware. A GPT USB will not boot on a Legacy-only BIOS.

2. Brand BIOS & One-Time Boot Menu Keys

Tap Immediately on Power-On
Brand BIOS / UEFI Setup Key One-Time Boot Menu Key
Dell F2 F12
Lenovo F1 or Fn + F2 F12 (or pinhole Novo button)
HP F10 F9
ASUS & Acer F2 or Del F8 (ASUS) / F12 (Acer)
SETUP TRAPS & OOBE

Missing NVMe Drives, Drive 0 Cleanup & Offline Local Admin

Trap 1: Missing NVMe Drive (Intel VMD / RST) 11th–14th Gen Intel laptops ship with Intel VMD/RST enabled in BIOS. Standard Windows ISOs lack this storage controller driver, showing zero drives during setup. Fix: click Load driver and load the OEM Intel RST/VMD F6 driver from USB (or toggle VMD/storage mode to AHCI in BIOS before a fresh install).
Trap 2: Drive 0 Clean Partitioning Choose Custom: Install Windows only. Delete existing partitions on Drive 0 (System, MSR, Primary, Recovery) until it shows Drive 0 Unallocated Space, select it, and click Next. Never delete partitions on a secondary data drive (Drive 1).
# Bypass online Microsoft Account in Windows 11 OOBE (press Shift + F10):
oobe\bypassnro
PC restarts → click I don't have internet → create a local IT admin account first, rename the PC (sysdm.cpl), then join the Domain / Entra ID.
⚠ Version Note: bypassnro may not work on newer Windows 11 builds
Microsoft has been removing oobe\bypassnro in newer Windows 11 builds. If the command does nothing or the I don't have internet button never appears, press Shift + F10 and run the alternative below. It opens the local account creation screen directly, so there is no restart step. Then continue the same way: create the local IT admin account, rename the PC, and join the Domain / Entra ID.
start ms-cxh:localonly
LESSON 05 OF 09 • FIELD OPS 02 • ONBOARDING & IDENTITY

New PC Prep, User Profiles & BitLocker

Onboarding new hires, rescuing corrupted user profiles without losing data, enforcing least-privilege accounts, and unlocking BitLocker screens are daily Tier-1 desk tasks.

1. User Profile Anatomy (C:\Users\<username>)

Personal Folders Desktop, Documents, Downloads, Pictures. In M365 environments, OneDrive Known Folder Move backs up Desktop & Documents automatically.
Hidden AppData AppData\Local (Outlook .ost cache, Teams cache, Chrome profiles) and AppData\Roaming (Outlook email signatures, app settings).
NTUSER.DAT Hidden user Registry hive (HKEY_CURRENT_USER) storing mapped drives, Outlook profiles, and preferences. If locked or corrupted, Windows cannot load the profile.
DATA LOSS TRAP

2. Corrupted / Temporary Profile Fix ("We can't sign into your account")

When NTUSER.DAT fails to load, Windows signs the user into a blank temporary profile at C:\Users\TEMP:

1. NEVER SAVE IN TEMP Warn the user immediately not to create or save files on that desktop—everything inside C:\Users\TEMP is wiped automatically on sign-out or reboot.
2. REBOOT FIRST Click Start → Restart once before touching Registry keys. Often an AV scan or update briefly locked NTUSER.DAT, and a clean restart restores the real profile.
3. BACK UP & REGENERATE Sign in as Local Admin, back up C:\Users\<user> data, remove the stale .bak profile entry in ProfileList (or rename the old folder), and have the user sign in to generate a clean profile.

3. Account Privileges & Day-1 New Laptop Prep Checklist

Local Admin vs. Standard User (lusrmgr.msc): Employees must work daily as Standard Users so malicious email attachments cannot silently install software or modify system settings. IT techs elevate via UAC using a dedicated Local Admin account.
01. UPDATES Run Windows Updates + OEM driver & BIOS updates.
02. POWER & LID Configure sleep timers & docked lid-close behavior.
03. DISPLAYS Test dual monitors (Win + P → Extend) & scaling.
04. CORE APPS Install & verify M365, Chrome, VPN, Teams, and AV.
05. IDENTITY Join Domain / Entra ID and verify OneDrive sync.
ENCRYPTION SOP • BITLOCKER

BitLocker Recovery Key Trap

A BIOS update, TPM reset, Secure Boot change, or docking station hardware change alters boot measurements and triggers the blue BitLocker Recovery screen asking for a 48-digit recovery key.

Where Tier-1 Retrieves the 48-Digit Key:
1. Ask the user for the first 8 characters of the Recovery Key ID displayed on screen.
2. Look up that Key ID in Microsoft Entra ID / Intune (Devices → Recovery keys), Active Directory (Computer Properties → BitLocker Recovery tab), or the user's personal Microsoft account (aka.ms/myrecoverykey).
LESSON 06 OF 09 • FIELD OPS 03 • SYSTEM RECOVERY

OS Repair Commands & Safe Mode

Before wiping and reimaging a corrupted Windows installation, run Microsoft's built-in image and file repair commands in the exact right order—or boot into WinRE to roll back bad updates and crashing drivers.

1. Repair Command Order of Operations (Admin CMD)

DISM First, SFC Second

sfc /scannow repairs corrupted Windows files by copying healthy replacements from the local Component Store (C:\Windows\WinSxS). If WinSxS is damaged, sfc fails until DISM repairs the component store image first.

1. Repair Windows Component Store Image First:
DISM /Online /Cleanup-Image /RestoreHealth
2. Scan & Replace Corrupted OS Files Second (then Reboot):
sfc /scannow
3. Check NTFS File System & Disk Integrity Online (No Reboot):
chkdsk C: /scan

2. Windows Recovery Environment (WinRE) & Safe Mode

Hold the Shift key while clicking Start → Power → Restart → click Troubleshoot → Advanced options:

Startup Repair Fixes missing or damaged boot configuration files (BCD) when Windows fails to boot past the logo.
Uninstall Updates Removes the latest Quality or Feature update when a laptop starts crashing right after Patch Tuesday.
System Restore Rewinds Windows drivers, Registry, and system files to a prior Restore Point without deleting personal documents.
Startup Settings → F4 / F5 (Safe Mode) Boots with minimal Microsoft drivers (F4 Safe Mode; F5 Safe Mode with Networking) to remove bad drivers or startup crashes.
LESSON 07 OF 09 • FIELD OPS 04 • STORAGE & PERFORMANCE

Storage, Resource Monitor & Slow PC Triage

When an external drive fails to appear in File Explorer or a user reports a sluggish laptop, Disk Management, Computer Management, Resource Monitor, and a structured 6-point triage sequence let you pinpoint the exact bottleneck in minutes.

1. Disk Management (diskmgmt.msc) & Computer Management

When a user plugs in a secondary SSD, HDD, or USB drive and nothing appears in File Explorer, open diskmgmt.msc to diagnose its three common states:

State 1: Offline Disk Occurs after disk signature collisions or SAN/dock reconnects. Right-click the disk label on the left column and select Online.
State 2: Unallocated Disk Brand-new unformatted drive. Right-click → Initialize Disk (GPT for modern Windows / >2 TB, MBR for legacy) → right-click unallocated space → New Simple Volume (format NTFS, assign drive letter).
State 3: Healthy Partition Without Drive Letter Partition already contains user data, just invisible in File Explorer. Right-click the volume → Change Drive Letter and Paths... → Add. NEVER format a partition that already contains user data!
Computer Management (compmgmt.msc): Single MMC console bundling Task Scheduler, Event Viewer, Shared Folders, Local Users and Groups (lusrmgr.msc), Device Manager (devmgmt.msc), Disk Management (diskmgmt.msc), and Services (services.msc).

2. Resource Monitor (resmon)

Launch via Win + R → resmon (or Task Manager → Performance → Open Resource Monitor). It goes deeper than Task Manager:

Disk Tab → Disk Activity Pinpoints the exact process (PID) and exact file path (C:\...) reading/writing MB/s when Disk is pinned at 100%.
Network Tab → TCP Connections Shows Processes with Network Activity alongside which remote IP/port is saturating bandwidth.
CPU Tab → Associated Handles Search a locked filename to see which process holds a file handle open when Windows blocks deletion or renaming.

3. The 6-Point "Slow PC" Triage Checklist

Ties Module 01 Together

Run through these six checks in order whenever a user reports "My PC is running really slow":

01. TASK MANAGER (Ctrl + Shift + Esc) Spot CPU, RAM, or Disk 100% spikes and end runaway tasks (or drill into resmon).
02. SYSTEM UP TIME (FAST STARTUP) If CPU Up time is multi-day, run a real Start → Restart to flush the hibernated kernel.
03. FREE SPACE ON C:\ (cleanmgr) SSD performance degrades when free space drops below 10–15%. Run Disk Cleanup (cleanmgr) / Storage Sense.
04. STARTUP APPS Disable high-impact non-essential apps in Task Manager → Startup apps.
05. PENDING WINDOWS UPDATES Check if Windows Update is downloading or installing a large feature update in the background.
06. WINDOWS DEFENDER QUICK SCAN Rule out background malware/adware CPU load via Windows Security → Quick scan.
LESSON 08 OF 09 • FIELD OPS 05 • UPDATES, EDITIONS & REGISTRY

Windows Update, Editions & Registry Basics

Know how to clear stuck Windows Updates, verify whether a workstation has the right Windows edition and architecture for corporate domain join, and safely navigate and back up the Windows Registry.

1. Windows Update Troubleshooting

Check Update History & Uninstall a Bad Patch Open Settings → Windows Update → Update history (inspect failed 0x800... error codes) → click Uninstall updates to remove a recent cumulative update (KB...) that broke an app or VPN.
Windows Update Troubleshooter Open Settings → System → Troubleshoot → Other troubleshooters → Windows Update → Run to repair hung update services and BITS queues.
# Reset Stuck Update Cache (SoftwareDistribution) in Admin CMD:
net stop wuauserv
net stop bits
ren C:\Windows\SoftwareDistribution SoftwareDistribution.old
net start wuauserv
net start bits

2. Windows Editions, Architecture & Lifecycle (winver)

Windows Home (Consumer Edition) Cannot join an on-premises Active Directory domain, lacks Group Policy Editor (gpedit.msc), lacks full BitLocker drive encryption management, and cannot host Remote Desktop (RDP). Must be upgraded to Pro before corporate onboarding.
Windows Pro / Enterprise + 64-bit vs. 32-bit Supports Domain Join, Microsoft Entra ID + Intune MDM, Group Policy, BitLocker, and Remote Desktop host. Modern PCs run 64-bit (x64) (C:\Program Files vs. legacy 32-bit C:\Program Files (x86)).
winver & Windows 10 End of Support (October 2025): Run winver (Win + R) to verify Edition (Home/Pro), Version (22H2, 24H2, 25H2), and OS Build. Because Windows 10 reached End of Support in October 2025, organizations migrating remaining Windows 10 laptops to Windows 11 must verify TPM 2.0, UEFI + Secure Boot, and supported CPUs.

3. Windows Registry Basics (regedit)

The Registry is Windows' hierarchical configuration database storing low-level OS, hardware, and application settings across two critical root hives:

HKEY_LOCAL_MACHINE (HKLM) Machine-wide settings affecting all users on the PC (drivers, services, ProfileList, installed software).
HKEY_CURRENT_USER (HKCU) Settings for the currently signed-in user only—stored physically inside that user's C:\Users\<username>\NTUSER.DAT file.
MANDATORY BACKUP RULE The Registry has no Undo button and wrong edits can prevent Windows from booting. Before editing or deleting any key (such as removing a .bak suffix under HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList), right-click the key → Export and save a .reg backup file.
LESSON 09 OF 09 • FIELD OPS 06 • QUICK FIELD EXTRAS

Quick Field Extras: Reliability Monitor, msconfig, Task Scheduler & PC Specs

Four lightweight built-in Windows utilities that are not always your first click—until you need to correlate crashes with recent updates, run a clean-boot isolation, inspect a scheduled login script, or pull full workstation hardware specs in seconds.

1. Reliability Monitor (perfmon /rel)

Event Viewer contains thousands of noisy entries. Reliability Monitor (Win + R → perfmon /rel) distills system stability into a clean day-by-day timeline so you can spot patterns in 10 seconds:

1–10 Stability Index Plots daily OS stability from 1 (unstable) to 10 (rock solid) across five rows: Application failures, Windows failures, Miscellaneous failures, Warnings, and Information events.
Correlate Crashes with Changes Check the blue Information row right before red X crash icons begin—it immediately shows if a Windows Update (KB...), driver, or app install triggered the crashes.
View Technical Details Click View technical details on any red crash entry to copy the exact Faulting Application Path, Faulting Module (e.g., ntdll.dll), and Exception Code into Tier-2 escalations.

2. System Configuration (msconfig)

Used primarily for Clean Boot isolation (ruling out third-party background software) and triggering Safe Mode remotely when holding Shift during restart isn't feasible:

Services Tab → Clean Boot Isolation Check "Hide all Microsoft services" at the bottom first, then click Disable all and restart. This disables third-party agents (AV, VPN, vendor bloat) while keeping core Windows networking and sign-in intact.
General & Startup Tabs Normal startup loads all services/drivers; Selective startup appears automatically during clean-boot testing. The Startup tab redirects straight to Task Manager → Startup apps.
BOOT TAB TRAP • SAFE BOOT LOOP Checking Boot → Safe boot in msconfig modifies the Boot Configuration Data persistently. Unlike WinRE F4/F5 (one-time Safe Mode), msconfig will boot the PC into Safe Mode on every restart forever until you reopen msconfig, uncheck Safe boot (or select Normal startup), and reboot.

3. Task Scheduler (taskschd.msc)

Controls automated background jobs, logon scripts, app auto-updaters, and scheduled backups. Click Task Scheduler Library on the left pane to inspect custom and third-party tasks:

Triggers & Actions Triggers define when a task runs (At log on, At startup, Daily schedule); Actions reveal the exact .exe, .bat, or .ps1 script path being launched.
Status & Last Run Result (0x0) Status shows Ready, Running, or Disabled. A Last Run Result of 0x0 means the task succeeded; non-zero hex codes (e.g., 0x1 or 0x80070002) indicate a script or missing-file error.
Common Desk Tickets Catching a flashing Command Prompt popup on every user login (rogue scheduled task), testing a failed backup job via Right-click → Run, or disabling broken legacy updaters.

4. Pulling PC Specs Fast (winver vs. systeminfo)

winver (2-Second GUI Popup) Run winver (Win + R) when you only need Windows Edition (Home/Pro/Enterprise), Feature Version (24H2/25H2), and OS Build.
systeminfo (Full CLI Hardware & OS Spec Sheet) Run systeminfo in cmd to pull Host Name, OS Version, Original Install Date, System Boot Time, System Manufacturer & Model, BIOS Version, Total Physical Memory (RAM), Domain, and installed Hotfix(s).
# Pull key OS, Uptime, Model & RAM lines in 2 seconds (Admin or Standard CMD):
systeminfo | findstr /B /C:"OS" /C:"System Boot" /C:"System Model" /C:"Total Physical Memory"
