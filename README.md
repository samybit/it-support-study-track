# Tier-1 IT Support Course

A hands-on study track for a Junior Service Desk / Tier-1 IT Support role. Each module is a self-contained interactive HTML lesson with labs and a final practical exam.

## Modules

| Module | Topic | What You Learn & Practice | Status |
|--------|-------|---------------------------|--------|
| 01 | Troubleshooting Methodology & Windows OS Basics | 6-step diagnostic loop, Task Manager, Device Manager, Services, Event Viewer, NTFS & shares, Windows install & BIOS, profiles & BitLocker, DISM/SFC/WinRE, Disk Management, Resource Monitor, slow-PC triage, Windows Update, registry, Reliability Monitor, msconfig | ✅ Complete |
| 02 | Practical Networking (Tier-1 Scope) | IPv4, subnet mask, default gateway, DHCP (169.254.x.x APIPA), DNS, Wi-Fi vs. LAN, VPNs, everyday ports (80, 443, 53, 3389, 445, 22), CLI labs (`ipconfig`, `ping`, `tracert`, `nslookup`) | ⬜ Planned |
| 03 | Active Directory & Entra ID | ADUC (users, computers, OUs, security groups), password resets, account lockouts, domain join, Group Policy (`gpupdate /force`), Entra ID (SSO & MFA resets) | ⬜ Planned |
| 04 | Microsoft 365 & Intune | Outlook repairs (`outlook.exe /safe`, mail profiles, shared mailboxes, calendar permissions), Teams cache, M365 Admin Center (licenses & offboarding), Intune MDM basics | ⬜ Planned |
| 05 | Printers & Peripherals | USB vs. network TCP/IP & print server setup, clearing the spool folder, restarting Print Spooler, driver fixes, docking stations & scanners | ⬜ Planned |
| 06 | Remote Support & Ticketing (ITIL Basics) | Ticketing terminology & lifecycle, priority triage, SLAs, escalation rules, remote screen-sharing tools | ⬜ Planned |
| 07 | Mock Interview & Scenario Drills | 60-90 second structured answers for classic Tier-1 scenarios, multi-ticket prioritization drills, positioning technical background for support interviews | ⬜ Planned |

## How to Use

1. Download the module's `.html` file (or open it through GitHub Pages if enabled).
2. Open it in any modern browser. No install needed.
3. Work through the lessons in order and run every lab on a real Windows PC.
4. Pass the final practical check for the module before moving on.
